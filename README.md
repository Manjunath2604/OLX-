# BazaarGo (OLX- Global Marketplace)

A modern, responsive cross-border marketplace React web application designed for seamless international trade with escrow protection.

## Features
- **Homepage (Global Marketplace)**: Cross-border search, delivery filters, top category icons, trust pillars, and local-to-global empowerment banner.
- **Product Listing (Browse & Discover)**: Category navigation, faceted filters (price slider, condition, shipping, seller ratings, regions), and product grid with verified seller badges.
- **Vendor Dashboard (Manage & Grow)**: Dark studio theme, KPI stats, interactive revenue line chart, order fulfillment pipeline, recent orders table, and category distribution.
- **Product Details (Buy with Confidence)**: Multi-image gallery with carousel, specifications, reviews, seller profile, and live translated chat modal.
- **Checkout (Secure Global Transactions)**: 3-step stepper, international shipping options with dynamic fee calculation, customs estimator, and escrow authorization modal.
- **Mobile App Experience**: Interactive smartphone simulator demonstrating mobile feed, navigation, and product interactions.
- **Prototype Switcher**: Persistent header for instant 1-click toggling between all 6 UI mockup screens.

## Tech Stack
- React 19 + Vite
- Tailwind CSS v4
- Lucide Icons

## Getting Started
```bash
npm install
npm run dev
```

## Deploying on Vercel
1. Push this repository to GitHub.
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import this repository (`OLX-`).
4. Framework Preset will be automatically detected as **Vite**.
5. Click **"Deploy"**.
